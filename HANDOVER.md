# HANDOVER.md

This file is no longer the source of truth. Start any session by reading, in order:

1. **`CLAUDE.md`** — protected areas, hard product rules, validation commands, working style.
2. **`PROJECT_STATUS.md`** — current state of the site and data (artists, events, guides, bindings, risks).
3. **`BACKLOG.md`** — active priorities, each tied to a GitHub issue.

Do not rely on older "next task" guidance from previous handovers (for example, proposals about new artists). The active priorities are whatever `BACKLOG.md` lists today.
