## SeatGeek price snapshots — permanently disabled (owner-confirmed 2026-07-15)

SeatGeek's API does not expose event pricing statistics for this client and never will: the inspected runs had both `SEATGEEK_CLIENT_ID` and `SEATGEEK_CLIENT_SECRET`, fetched every eligible exact-event listing with HTTP 200, and received null for every pricing-stat field (`lowest_price`, `average_price`, `highest_price`, and related), so no usable snapshot can be built. This is a permanent provider-API limitation, not a pending entitlement. The scheduled trigger in `seatgeek-price-snapshots.yml` was removed (only `workflow_dispatch` remains, as a reversible escape hatch should SeatGeek ever ship pricing-stat access). `SEATGEEK_PRICE_DISPLAY_ENABLED` may be left `true` (owner-confirmed 2026-07-15) but is **inert**: the display gate only renders a snapshot when a fresh cached row exists, and none are ever written. No owner action is outstanding; SeatGeek remains a CTA-only provider, and price comparison is served by Vivid Seats, TicketNetwork, and StubHub International.
